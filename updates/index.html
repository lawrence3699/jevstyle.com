Updates

Model and package releases, newest first. Each entry links to its release notes or model page.

  1. 2026-10-28Package
    jev-style 0.6.2

    Refreshed the PyPI description and added direct links to model selection and benchmark protocols. Runtime behaviour is unchanged.

  2. 2026-10-28Package
    jev-style 0.6.1: faster local workflows

    Added runnable support-ticket, fallback-routing and receipt-review recipes, plus a Semantic Router example.

  3. 2026-10-27Model
    Jev-Style 2B v4

    The first Jev-Style model that reads images, through its PyTorch build. MLX and GGUF builds are text-only.

  4. 2026-10-27Package
    jev-style 0.6.0

    Added 2B v4 and image requests. --release 2b now selects 2B v4; the default release stays 0.8B v3.

  5. 2026-10-17Package
    jev-style 0.5.0

    Added compressed request bodies and tighter request checks for compatibility with current official SDKs.

  6. 2026-10-03Model
    Jev-Style Cascade 9B

    A cascade configuration: our 2B answers first and sends uncertain questions to a larger model.

  7. 2026-10-02Package
    jev-style 0.4.0

    Added CUDA graphs for the PyTorch backend and confidence cascades across model tiers.

  8. 2026-09-27Model
    Jev-Style 2B v3

    Released with PyTorch, MLX and GGUF builds, and available through jev-style 0.3.0.

  9. 2026-09-26Package
    jev-style 0.2.0 on PyPI

    The package became installable with pip and gained an eval command for comparing engines on your own questions.

  10. 2026-09-25Package
    First public jev-style release

    Shipped a local API server, six agent skills, a Claude Code guard, an MCP server and an evaluation command.

  11. 2026-09-24Model
    Jev-Style 0.8B v3

    A smaller long-input, multilingual model, and the default local text model today.

  12. 2026-09-23Model
    MacJev 322M

    A 322M decision model for local Mac agents.

  13. 2026-09-23Model
    Decision 2B v2

    Calibrated English classification at 2B.

  14. 2026-09-21Model
    Decision 2B v1

    The first published decision model. Superseded by v3 and v4.
