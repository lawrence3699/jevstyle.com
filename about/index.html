About

JevStyle builds small decision models you can run yourself

Everyday classification, routing, and scoring should not need a large model or a cloud account. Give a model your options and it returns a probability for each one.

Get API keyExplore modelsContact

What we do

Decisions, not chat

Give a model text or JSON and typed yes/no, choice, or ordered-score questions. It scores the options in one forward pass. Use it for support ticket classification, request routing, or an additional review signal for agent tool calls. It does not generate free-form chat replies.

Sources

Official sources and independence

Jev-Style names the model family, jev-style is the Python package, and JevStyle is the brand and website. The model comparison separates releases, inputs, backends, and weight sizes.

After dependencies and weights are downloaded, local inference runs on your machine. The Hugging Face demo and hosted API are separate services that receive inputs sent to them. The hosted API currently uses 2B v4 Q4_K_M for text only, with up to 8,000 input tokens and one request at a time. Its limits differ from the local 2B v4 PyTorch model, which also supports images. See the current API reference.

Use this website, GitHub, PyPI, and Hugging Face to verify releases and capabilities. JevStyle is not affiliated with or endorsed by TypeSafe AI (Jev), the Laya authors, Alibaba Cloud, or the Qwen team.

Project code and published weights are licensed under Apache-2.0. Training provenance differs by release: the Jev-Style-2B-Decision-v4 model card discloses soft-label distillation from TypeSafe Jev 1.14 through its public API. Published performance numbers are project self-runs under stated protocols, not official leaderboard positions or guarantees for arbitrary tasks.
