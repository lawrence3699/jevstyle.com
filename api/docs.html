Quick start

Auth

Authorization: Bearer jev_YOUR_KEY

Bases

Site / docs:     https://jevstyle.com/api
Control plane:   https://api.jevstyle.com/control/v1
Inference (s1):  https://api.jevstyle.com/v1/systemone

Example (stage 1 — will fail with 503 today)

curl -sS https://api.jevstyle.com/v1/systemone \
  -H "Authorization: Bearer jev_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "state": "I was billed twice. Please refund one charge.",
    "questions": {
      "refund": {"type": "noul", "instructions": "The customer asks for money back."},
      "team": {
        "type": "choice",
        "instructions": "Which team should handle this?",
        "criteria": {"billing": "charges, refunds", "tech": "bugs", "sales": null}
      }
    }
  }'

Limits

20 RPM · 500 / day (UTC) · concurrency 1 · ~8k tokens soft cap · 25,600 hard cap · no SLA.

See project file api-errors-v1.md. Stage 0 inference returns 503 inference_not_ready.
