Authentication

Inference requests require an API key. Create keys in Console after you sign up — no application form.

API key header

Send one of:

Authorization: Bearer jev_YOUR_KEY

or

X-API-Key: jev_YOUR_KEY

Prefer Authorization: Bearer. Missing or invalid key → 401.

Get a key

  1. Register or log in (email/password or Google).
  2. Open Console → Create API key.
  3. Copy the plaintext key immediately — it is shown only once. Up to 3 keys per account.

Account session (Console)

Console uses an HTTP-only session cookie on api.jevstyle.com with credentials: "include". Browser CORS allows only https://jevstyle.com. OAuth client secrets never ship in the frontend.

Google sign-in is available via /control/v1/auth/google/start (or the button on Log in / Register).

Email/password and Google use separate accounts, even for the same email. Google sign-in requires a verified Google email. Accounts are never automatically linked by email.

Email/password accounts must verify their email before creating or using API keys. Use Forgot password to recover an email/password account. Verification and password reset revoke old sessions and API keys; sign in again and create new keys afterwards.

Revoke

Revoke any key anytime in Console. Revoked keys fail with 401.
