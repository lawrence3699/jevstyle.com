Limits

Fair-use free tier. No SLA. Limits may change. Best effort.

DimensionValueOn exceed
Requests / minuteElastic — no fixed per-account RPM cap429 + Retry-After
Requests / day10,000 successful / account (UTC)429
Concurrent in-flightElastic — up to 3 while idle; reduced as demand increases429
Input cap / request8,000 model tokens (state + all questions), max 32,000 UTF-8 bytes413
API keys / account3Create disabled in Console

Requests are admitted while shared service capacity is available. Busy service capacity returns 429 with Retry-After. Daily and concurrent limits are per account and shared by all of its keys (up to 3, for rotation). Daily quota counts successful inference only; rejected, failed or timed-out requests are not charged.

Best practices

  • Backoff on 429 / 504 / 5xx.
  • Keep state + questions under the soft cap.
  • Concurrency is shared by all keys of an account. Idle capacity allows up to 3 concurrent requests; competing accounts and busier capacity reduce that share to 2 or 1. Existing requests finish normally. Retry on 429 with backoff.
  • Do not resell quota or scrape the free tier.

Hosted API status and local installation

Checked 2 November 2026: the public health endpoint reported ready for inference. This is a dated health observation, not a permanent uptime claim or an end-to-end inference test. Check live health for a new observation.

Live health has not been checked in this page session.

The hosted API serves text-only 2B v4, with an 8,000-token input cap. Shared capacity is elastic; see current quota and concurrency limits. A 429 capacity response asks you to retry; it is not by itself evidence of maintenance.

Run JevStyle locally without a hosted API key. Local weights and Hugging Face demos are separate from this hosted endpoint. Install the official jev-style package for local inference; TypeSafe/OpenRouter Jev credentials and agent simulation are different paths.
