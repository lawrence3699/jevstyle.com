Daily quota counts successful inference only. Stage 0 503 responses do not spend daily quota. Global guards: 60 RPM, 1500 successful requests/day, 1 in-flight request. Byte guards are not exact tokenizer counts.

Best practices

  • Backoff on 429 / 504 / 5xx.
  • Keep state + questions under the soft cap.
  • One in-flight request per key unless you create another key (max 3).
  • Do not resell quota or scrape the free tier.
