Independence

This hosted API serves the open-weight Jev-Style-2B-Decision-v4 model. It is independent and not affiliated with, endorsed by, or operated by TypeSafe AI. Do not describe it as official TypeSafe / Jev hosting.

Free tier

Limits may change. No SLA. Abuse, resale of quota, or infrastructure attacks lead to key revocation.

Model & licence

Weights are Apache-2.0. Review the Hugging Face model card training-data notes before commercial use. The service does not guarantee your downstream compliance.

Privacy

Keys are stored hashed. Request text (state and questions) is not stored. Metadata such as time, status, and key ID is logged for rate limits and security. Do not submit secrets or government IDs in state. See Privacy.

Public pages of this website (not Console or sign-in pages) count page views with Cloudflare Web Analytics, which sets no cookies and does not see API requests.

Decisions only

The model scores options you provide. It does not generate free-form text or take actions.
