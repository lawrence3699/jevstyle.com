Overview

Free hosted API for Jev-Style Decision 2B v3: send a state and typed questions, get calibrated probabilities in one pass. Independent project · not TypeSafe.

Quick start

  1. Create an account (email or Google). Email/password accounts must verify their email first.
  2. Open Console → Create API key (up to 3 per account; shown once).
  3. Call POST https://api.jevstyle.com/v1/systemone with Authorization: Bearer ….

Bases

Site / docs:   https://jevstyle.com/api
Console:       https://jevstyle.com/console
Control plane: https://api.jevstyle.com/control/v1
Inference:     https://api.jevstyle.com/v1/systemone

Example

curl -sS https://api.jevstyle.com/v1/systemone \
  -H "Authorization: Bearer jev_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "state": "I was billed twice. Please refund one charge.",
    "questions": {
      "refund": {"type": "noul", "instructions": "The customer asks for money back."},
      "team": {
        "type": "choice",
        "instructions": "Which team should handle this?",
        "criteria": {"billing": "charges, refunds", "tech": "bugs", "sales": null}
      }
    }
  }'

Question types

typeMeaning
noulYes/no — probability near 0–1
choicePick one — criteria map required
scoreOrdered scale — 2–10 criteria strings
