Home / Endpoints · Jev-Style API

Endpoints

All public traffic goes through https://api.jevstyle.com. Do not call internal inference ports.

Inference

MethodPathAuthNotes
POST/v1/systemoneAPI keyDecision API: calibrated probabilities for noul / choice / score questions
GET/v1/modelsAPI keyLists the hosted model (jev-style-2b-decision-v4) with its context and input limits; also a quick way to check that a key works

Request body

state (string) + questions (map of id → question). Each question has type, instructions, and optional/required criteria.

{
  "state": "Customer message…",
  "questions": {
    "refund": {
      "type": "noul",
      "instructions": "The customer asks for money back."
    },
    "team": {
      "type": "choice",
      "instructions": "Which team should handle this?",
      "criteria": {
        "billing": "charges, refunds",
        "tech": "bugs, outages",
        "sales": null
      }
    },
    "urgency": {
      "type": "score",
      "instructions": "How urgent?",
      "criteria": ["can wait", "this week", "today"]
    }
  }
}

Usage

Prefer Console (session), or call control plane GET /control/v1/usage with a Bearer key (per-key usage) or session cookie (totals and per-key items for active keys).

Control plane (account)

Register, login, keys — see Authentication and auth-account-plan-v1.md. Base: https://api.jevstyle.com/control/v1.
