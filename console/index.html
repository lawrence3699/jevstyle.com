Quick start

  1. Create a secret key on the API keys page and store it somewhere safe.
  2. Make it available to your code: export JEV_API_KEY="jev_…"
  3. Send your first request:
curl https://api.jevstyle.com/v1/systemone \
  -H "Authorization: Bearer $JEV_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "state": "I was billed twice. Please refund one charge.",
    "questions": {
      "refund": {"type": "noul", "instructions": "The customer asks for money back."}
    }
  }'
import os
import requests

response = requests.post(
    "https://api.jevstyle.com/v1/systemone",
    headers={"Authorization": f"Bearer {os.environ['JEV_API_KEY']}"},
    json={
        "state": "I was billed twice. Please refund one charge.",
        "questions": {
            "refund": {"type": "noul", "instructions": "The customer asks for money back."},
        },
    },
    timeout=70,
)
response.raise_for_status()
print(response.json()["answers"]["refund"]["noul"])  # probability of "yes"
