    import os
import requests

response = requests.post(
    "https://api.jevstyle.com/v1/systemone",
    headers={"Authorization": f"Bearer {os.environ['JEV_API_KEY']}"},
    json={
        "state": "I was billed twice. Please refund one charge.",
        "questions": {
            "refund": {"type": "noul", "instructions": "The customer asks for money back."},
        },
    },
    timeout=70,
)
response.raise_for_status()
print(response.json()["answers"]["refund"]["noul"])  # probability of "yes"

Rate limits

          
Limits apply to your whole account and are shared by all of its keys.

          

            

              
ModelConcurrentRequests per minuteRequests per dayInput per request

              
                

                  jev-style-decision-v3

  • The daily quota resets at 00:00 UTC. Only successful requests count; failed, rejected and timed-out requests are free.
    • 
            
  • Over a limit, requests get 429 (with Retry-After for the per-minute limit). Input over the token cap gets 413.
    • 
            
  • Up to 3 active API keys per account. Extra keys are for rotation, not extra capacity.
