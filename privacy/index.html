Privacy

What JevStyle handles depends on where you run the model.

Reviewed 2026-10-31

Local models

After dependencies and weights are downloaded, local inference runs on your machine. JevStyle does not receive your inputs.

Hosted API

Request text (state and questions) is not stored. Metadata such as time, status, and key ID is logged for rate limits and security. Do not submit secrets or government IDs in state.

Accounts and API keys

An account uses your email address for verification and sign-in. API keys are stored hashed.

This website

Public pages count page views with Cloudflare Web Analytics, which sets no cookies and does not see API requests. Console and sign-in pages are not counted.

Hugging Face demo

The demo runs on Hugging Face and is a separate service. Inputs you send there are handled by that service.
