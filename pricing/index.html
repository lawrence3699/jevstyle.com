Pricing and license

The hosted API is free, and the published weights are open. There are no paid plans.

Hosted API

Free. Each account gets 10,000 requests a day. Text only, up to 8,000 input tokens per request, one request at a time.

Limits may change, and there is no SLA.

Open weights

Free to download and run on your own hardware, with no API key.

PyTorch, MLX and GGUF builds are available. Their inputs differ by model.

The license, in plain terms

The hosted service does not guarantee your downstream compliance. Read the terms, or contact us with questions.
