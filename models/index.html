Three ways to run them

The hosted API and Hugging Face demo are separate services and receive what you send them. Local inference stays on your machine once the model is downloaded.

Hosted API

Runs 2B v4 Q4_K_M for text only, with up to 8,000 input tokens and one request at a time.

Get API keyAPI docs

Your own machine

Python 3.10+, inside a virtual environment. PyTorch reads text and images; MLX and GGUF read text.

python -m pip install "jev-style[torch]"
jev-style serve --release 2b --backend torch
# Open http://127.0.0.1:8765
