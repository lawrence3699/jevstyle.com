常见问题

可以离线运行吗？

可以。安装依赖并下载模型后，输入都在本机处理。在线 Demo 和托管 API 是独立服务，会收到你发送的内容。

应该选哪个模型？

文本任务从 0.8B v3 开始，再用自己的数据对比 2B v4。图片输入需要 2B v4 的 PyTorch 版；MLX 和 GGUF 仅支持文本。

它会生成聊天回复吗？

不会。它为是/否、多选和有序评分问题返回概率。不确定的情况交给人工或大模型。

项目信息

版本

Python 软件包为 jev-style 0.6.3。2B v4 已于 2026-10-27 发布：PyTorch 支持文本与图片，MLX 和 GGUF 仅支持文本。默认本地文本模型为 0.8B v3。

托管 API

托管 API 使用 2B v4，仅支持文本，上下文 8,192 token、输入上限 8,000 token；目前没有按账号的固定限额，容量共享，忙时返回 429 并带 Retry-After。本地模型与 Hugging Face Demo 是独立入口，托管服务的状态不代表本地模型不可用。查看带日期的服务状态与实时健康检查；本地安装不需要托管 API key。

训练出处

2B v4 部分训练使用 TypeSafe Jev 1.14 公共 API 生成的软标签。项目独立维护，无 TypeSafe 隶属关系。软件包不附带教师原始回答数据集，不代表训练未使用教师输出。参见模型与训练来源。
