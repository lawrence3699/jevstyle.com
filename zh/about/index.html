关于 JevStyle

用于本地分类、路由与评分的开源工具。小型决策模型为预定义选项返回概率。

维护者：严超亮（Chaoliang Yan） · 内容核对：2026-10-29 · English

项目能做什么？

JevStyle 接收文本或 JSON 以及是/否、多选或有序评分问题，一次前向计算返回各选项的概率。可用于客服工单分类、请求路由和 Agent 工具调用的辅助审核，不生成自由文本回复。

Python 包提供本地服务、Python 客户端、MCP 工具和 Agent 技能。2B v4 的 PyTorch 构建还支持图片输入；MLX 与 GGUF 构建仅支持文本。

模型、软件包和服务的区别

Jev-Style 是模型系列名称，jev-style 是 Python 包名，JevStyle 是网站和项目名称。模型对照表（英文）列出不同版本和后端。

安装依赖并下载模型后，本地推理在你的机器上执行。在线 Hugging Face Demo 与托管 API 是独立服务；发送给它们的输入由对应服务处理。托管 API 当前维护中，文档描述 2B v3 服务，不能将它与本地 2B v4 的输入上限混用。

许可证、出处与限制

项目代码和已发布模型权重使用 Apache-2.0 许可证。各模型卡记录基础模型、训练来源与限制。JevStyle 与 TypeSafe AI（Jev）、Laya 作者、Alibaba Cloud 或 Qwen 团队无隶属或背书关系。

项目名称不代表使用所有版本都相同的训练方法。2B v4 模型卡披露了通过 TypeSafe Jev 1.14 公共 API 获得的软标签蒸馏来源；请按版本核查模型卡。

公开性能数字是附带协议的项目自测，不等同于官方排行榜名次或任意任务上的保证。参见评测与复现（英文）；上线前请在自己的数据上检查准确率、校准和回退策略。
