关于我们

JevStyle 开发能在自己机器上运行的小型决策模型

日常的分类、路由和评分，不一定需要大模型或云账号。给出选项，模型返回每个选项的概率。

获取 API key查看模型（英文）联系我们

定位

我们做什么

给模型文本或 JSON，以及是/否、多选或有序评分问题，一次前向计算返回各选项的概率。可用于客服工单分类、请求路由和 Agent 工具调用的辅助审核，不生成自由文本回复。

本地运行下载后在你的机器上推理。
一次算完一次前向给所有选项打分。
开放权重代码和权重使用 Apache-2.0。
公开方法测评协议和限制都写清楚。

做事方式

我们怎么做事

  • 说明数字怎么来的公开的成绩都是项目自测，并写明协议和限制。见评测与复现（英文）。
  • 写明训练来源每个模型卡记录基础模型和训练来源。2B v4 的蒸馏来源已在模型页（英文）公开。
  • 如实显示服务状态首页显示托管 API 的实时状态，本地模型不受它影响。
  • 保留回退不确定的结果应交给人工或更大的模型。见评估指南（英文）。

来源

官方来源与独立性

Jev-Style 是模型系列名称，jev-style 是 Python 包名，JevStyle 是品牌和网站名称。安装依赖并下载模型后，本地推理在你的机器上执行。Hugging Face Demo 与托管 API 是独立服务；托管 API 当前使用 2B v4，仅支持文本，最多 8,000 个输入 token，一次处理一个请求。

以本网站、GitHub、PyPI 和 Hugging Face 为核查入口。JevStyle 与 TypeSafe AI（Jev）、Laya 作者、阿里云或 Qwen 团队无隶属或背书关系。2B v4 的部分训练使用 TypeSafe Jev 1.14 公共 API 生成的软标签。

已发布的性能数字是项目在明确协议下的自测，不是官方榜单名次，也不保证适用于任意任务。
