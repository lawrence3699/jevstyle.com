Questions

What is JevStyle?

JevStyle is an independent open-source project by Chaoliang Yan: small decision models (Jev-Style-0.8B-Decision-v3 and Jev-Style-2B-Decision-v4) and the jev-style Python package. Give it text, or an image with 2B v4, plus yes/no, choice or score questions, and it returns a probability for every option. Its local server accepts /v1/systemone requests. Code and weights are Apache-2.0, and the project is not affiliated with TypeSafe. Compare it with other open-source Jev alternatives.

Can JevStyle run offline?

Yes. After installing dependencies and downloading a model, inputs stay on your machine. The online demo and hosted API are separate services and receive what you send them.

Which model should I use?

Start with 0.8B v3 for text, then compare 2B v4 on your own examples. Image input needs the 2B v4 PyTorch build; MLX and GGUF builds are text-only.

Does it write chat replies?

No. It returns probabilities for yes/no, choice, and ordered-score questions. Send uncertain cases to a person or a larger model.

Project facts

Releases

The Python package is jev-style 0.6.3. 2B v4 was released on 2026-10-27: PyTorch supports text and images; MLX and GGUF builds are text-only. The default local text model is 0.8B v3.

Hosted API

The hosted API runs 2B v4 for text only, with an 8,192-token context and an 8,000-token input cap; there are no fixed per-account limits at the moment, capacity is shared, and a busy service returns 429 with Retry-After. Local models and the Hugging Face demo are separate entry points; hosted-service availability does not determine whether a local model works. Check dated service status and live health. Local installation needs no hosted API key.

Maintainer

Chaoliang Yan (GitHub: lawrence3699). JevStyle is independent and is not affiliated with or endorsed by TypeSafe.

Training provenance

2B v4 was trained in part on soft labels distilled from TypeSafe Jev 1.14 through its public API. JevStyle is independently maintained by Chaoliang Yan, with no TypeSafe affiliation or endorsement. The package does not bundle raw teacher-response datasets; this does not negate the use of teacher outputs in training. See the model and training sources.
