Open-source Jev alternatives you can run locally

Several open projects answer the same kind of request as TypeSafe's hosted Jev: a state plus yes/no, choice or score questions, with a probability for each answer. They differ in model size, hardware and interface.

Source review: 5 November 2026 · Each project's own README · Written by the JevStyle project, not an independent review

Which open-source Jev alternative fits?

Choose by hardware first, then by interface. On a laptop CPU or an Apple silicon Mac, the small models fit: JevStyle (0.8B and 2B), Kev-0.8B, or Laya's 322M and 421M encoders. With an NVIDIA GPU you can also run larger models, such as Kev-4B to Kev-27B, OpenJev-4B or the DiffusionGemma model in razorback16's OpenJev server. If you want one local daemon that pulls several authors' models by name, look at Ollaya.

Most of these projects accept TypeSafe's /v1/systemone request shape, so a client written for one can usually call another. Test them on your own examples: the numbers each project publishes come from different test sets.

What is a Jev-style decision model?

A decision model, also called a System One model, reads a state (text, JSON, and for some models an image) together with typed questions. It returns a probability for every option in one forward pass instead of writing an answer. TypeSafe offers this as the hosted Jev service. The projects below are open-weight implementations of the same interface; none of them is Jev's own model.

How accurate are they?

No single controlled test covers all of these projects, and each README reports different test sets, so their numbers cannot be compared with each other. The public Decision Index board scores open decision models under one protocol. Since 4 November 2026 it lists Jev-Style-2B-Decision-v4 at Public 44.37 and Full 34.53, and Jev-Style-0.8B-Decision-v3 at Public 17.0 and Full 12.5.

Two JevStyle self-runs compare with other systems on the same rows:

  • Hosted Jev is more accurate. On the 231 public JevBench v1.4.1 items, Jev 1.13.0's published accuracy is 86.6%. 2B v4 scored 74.9% (95% CI 68.9–80.0%) in a project self-run.
  • Against Laya. On 77-intent Banking77, 400 rows the model never trained on, 0.8B v3 scored 68.2%. The best of three official Laya checkpoints scored 49.2% when the project re-ran it on the same rows.

Protocols and limits are on the 2B v4 model card, the 0.8B v3 model card and the benchmarks page. With enough labelled data, a trained classifier can still win: see the six-intent routing test.

When JevStyle fits, and when something else fits better

  • JevStyle fits a laptop or an Apple silicon Mac, a Python workflow, yes/no questions about images with 2B v4, or an agent that needs MCP tools or a Claude Code guard. You can try the free hosted API before running it yourself.
  • Hosted Jev is more accurate on JevBench and needs no hardware. Your requests go to TypeSafe's service.
  • Kev fits if you want to fine-tune on your own labels, or need a larger model on a big GPU.
  • Laya fits many languages on a CPU, or a TypeScript app.
  • Ollaya fits if you want one local daemon that serves several authors' models.

Try JevStyle locally

# Apple silicon
python -m pip install "jev-style[mlx]"
# CPU or CUDA instead: python -m pip install "jev-style[torch]"
jev-style serve

The server listens on http://127.0.0.1:8765 and accepts POST /v1/systemone requests, so a client written for another systemone-compatible server can call it. Run locally covers backends and offline use.
